# Security

Please do not report a vulnerability in a public issue.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository.
Say what is affected and how to reproduce it.

This repository holds the WooCommerce plugin only. It contains no keys, no credentials and no Payshen
infrastructure. Never paste an API key (`ps_live_...`, `ps_test_...`) or a webhook signing secret (`whsec_...`)
into an issue, a pull request or a log you share: if one is exposed, roll it in the Payshen dashboard
(Developers → API keys, Developers → Webhooks).

Supported: the latest release.
